### P5GO — Quick Commerce App

P5GO is a **mobile-friendly quick commerce web application** designed to make everyday grocery shopping fast, simple, and convenient. The project features a wide range of products organized into multiple categories, responsive layouts, product search and filtering, a shopping cart, checkout and ordering functionality, user profiles, past orders, customer support, and a persistent dark mode.

Built using **HTML, CSS, and JavaScript**, P5GO focuses on a clean user experience across both desktop and mobile devices. It is designed as a **college project/demo application** showcasing the core features of a modern e-commerce platform.

**Tech Stack:** HTML5 • CSS3 • JavaScript • LocalStorage • Responsive Web Design

**Features:** Product Categories • Search & Filters • Shopping Cart • Checkout • Orders • Profile • Dark Mode • Mobile Responsive UI • Customer Support
