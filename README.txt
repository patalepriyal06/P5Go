P5GO — Quick Commerce College Project

Pages:
- index.html — home/storefront
- shop.html — full product catalogue
- categories.html — category browser
- profile.html — account/profile only
- orders.html — past orders only
- support.html — customer support

Branding:
- Uses the original text-only P5GO header branding.
- No custom logo image is included.

Pricing note:
The catalogue uses affordable, India-style local-demo pricing for a college project rather than premium NCR-style quick-commerce pricing. Actual retail prices vary by brand, city, pack size, season and promotions.

Data:
Cart, theme, profile and past orders are stored in localStorage so they continue across these pages on the same device/browser.
