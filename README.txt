P5GO — Quick Commerce Website

This is the browser-first version of P5GO. It is a normal responsive website designed to work directly in Chrome, Firefox, Safari and mobile browsers.

Pages:
- index.html — Home / storefront
- shop.html — full product catalogue
- categories.html — category browser
- profile.html — customer profile
- orders.html — order history
- support.html — customer support

Features:
- Responsive mobile, tablet and desktop layout
- Search, category filtering and sorting
- Shopping cart with quantity controls
- Checkout demo and local order history
- Profile editing stored on the same browser/device
- Light / dark mode
- Support-page tabs for Terms, Blog and Privacy
- Footer copyright line and Made with love in Mumbai signature
- Affordable India-style demo pricing
- Separate Profile and Orders navigation
- No Android app shell, manifest or service worker

Data:
Cart, theme, profile and past orders are stored in localStorage so they persist across pages on the same browser/device.

Note:
This is a front-end college-project demo. It does not process real payments or create real deliveries.


Catalogue: 344 products across 18 categories, including Sweets and Tea & Coffee.
